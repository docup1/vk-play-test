# vk-play-test

Два тестовых задания на C# (.NET 9): `task1` и `task2`.

## Общий подход к архитектуре

Оба решения собраны по одному шаблону — классический DDD из четырёх отдельных
class library-проектов: **Domain** (только интерфейсы и модели с конструктором),
**Application** (сценарии, использует интерфейсы Domain), **Infrastructure**
(реализует интерфейсы Domain), **Presentation** (точка входа и DI — единственное
место, где слои связываются). Application и Infrastructure не ссылаются друг на
друга. Внешних NuGet-пакетов нет, JSON — `System.Text.Json`.

## task1 — автоматизация Black Myth: Wukong Benchmark Tool

**Задание.** Инструмент на C#, который локально и полностью автоматически прогоняет
бенчмарк из Steam дважды: сначала с настройками, где узкое место — процессор, затем
с настройками максимальной нагрузки на видеокарту. Нужно самому применить настройки,
запустить и дождаться каждого прохода, затем получить и распарсить результаты и
вывести характеристики ПК, результаты и настройки обоих тестов.

**Реализовано.** CLI `wukongbench`: находит установку бенчмарка через Steam,
собирает характеристики ПК (WMI), применяет настройки в `GameUserSettings.ini`
(с бэкапом и последующим откатом), запускает бенчмарк, отыгрывает меню, ждёт появления
нового файла результатов, парсит его JSON (FPS avg/min/max, 1% low, frame time, VRAM,
загрузка CPU/GPU) и печатает отчёт плюс `report.md` / `report.json`. Есть режим
`--diagnostics`, конфигурация в `appsettings.json` и 33 теста, включая тесты правил
зависимостей слоёв. Требует Windows и прав администратора.

Подробности — в [`task1/README.md`](task1/README.md).

## task2 — погода по списку городов (wttr.in)

**Задание.** Загрузить список городов из файла в память, для каждого уникального
города получить данные через `https://wttr.in/{City}?format=j1`, завести модель
`WeatherData` (город, текущая температура в °C, страна), вывести погоду по каждому
городу и статистику по странам (количество городов, средняя, минимальная и
максимальная температура). Консольное приложение на C#, внешние пакеты запрещены,
все значения вычисляются кодом.

**Реализовано.** Консольное приложение `WeatherApp`: читает `Cities.txt`, убирает
дубликаты без учёта регистра, последовательно опрашивает API с повторами, считает
статистику по странам и выводит:

```
Moscow, Russia +12 °C
...
Austria - 2 cities, avg: +15 °C, min: +13 °C, max: +16 °C
```

Недоступный город не ломает отчёт — он пропускается с указанием причины.

Подробности — в [`task2/README.md`](task2/README.md).
